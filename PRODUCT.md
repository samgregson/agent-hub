# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Engineers working with an agent on project material.

## Product Purpose

Agent Hub is a project workspace for collaborating with an agent on documents, models, calculations, and inspectable outputs.

## Operating Context

Projects group conversations, files, IFC models, documents, reusable functions, workflows, and artifacts. Engineers inspect source material and review proposed changes.

## Capabilities and Constraints

Keep conversations central, preserve human approval for consequential changes, and keep project state owned by Agent Hub. The frontend hosts independently deployed MCP Apps.

## Brand Commitments

Agent Hub. Avoid neon green on black and a generic corporate appearance.

## Product Principles

- Make the agent and its work legible.
- Keep source material and outputs inspectable.
- Give engineers control over changes.
